Grounding Justification for Medical Assistant Chatbot

1. Retrieval-Augmented Generation (RAG):
The primary grounding mechanism is the vector database (ChromaDB). Every response generated by the system must be derived from the retrieved chunks.

2. Source Attribution:
The system tracks 'source_file' and 'page' metadata for every chunk. In the UI, the user can toggle "Show Sources" to see exactly where the information originated.

3. Multi-Agent Validation:
The LangGraph architecture includes a 'Validator' node. The Validator's role is to compare the Researcher's output against the original retrieved documents. If the Validator detects a hallucination or information not present in the source, it triggers a retry or requests clarification.

4. Prompt Engineering:
Prompts for both agents include explicit instructions to "only use the provided context" and "state if the answer is not found in the documents."

5. Human-In-The-Loop (HITL):
For high-stakes medical advice, the system interrupts the flow and requires a human operator (healthcare professional) to approve the response before it is sent to the end-user.
